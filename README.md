# Pole Dance Kiseleva — сайт студии

Одностраничный сайт студии танцев на пилоне (Москва, ул. Саянская 7, м. Новогиреево) в серо-золотой гамме: графитово-серые и серебристые секции с золотом, собственные линейные рисунки и ар-деко орнаменты. Запись — через онлайн-запись студии на YCLIENTS; заявки «Перезвоните мне», статистика и правка текстов — в кабинете `/admin`.

Стек: Vite · React 19 · TypeScript · CSS; сервер — одна Vercel Function (`api/index.ts` → `server/router.ts`), данные в Upstash Redis (локально — папка `.data/`). Шрифты: Cormorant Garamond, Manrope, Jost.

## Запуск

```bash
npm install
npm run dev        # сайт http://127.0.0.1:5180, кабинет http://127.0.0.1:5180/admin
npm run build      # проверка типов и сборка в dist/ (сайт + кабинет)
npm run photos     # пересобрать фото из _source/ в public/photos/ и картинку-превью og.jpg
```

Пароль кабинета — в `.env.local` (`ADMIN_PASSWORD`), файл в git не попадает. Пример переменных — `.env.example`.

## Блоки страницы

1. Первый экран: золотая пыль, свет за курсором, меняющееся слово, фото в рамке с ар-деко аркой и лучами, рейтинг Яндекса.
2. Бегущая золотая строка с направлениями.
3. Студия: факты с рисунками, неоновая вывеска и выключатель «день / неон» (зал на фото переходит в вечерний неон, вывеска загорается), экскурсия по студии — нарисованная схема зала с точками, у каждой точки фото целиком и рассказ, автопрокрутка.
4. Направления: шесть направлений с рисунками, фото целиком на размытой подложке, тест «Какое направление вам подходит».
5. Галерея: 3D-карусель вокруг пилона и лента горизонтальных кадров.
6. Цены: калькулятор абонементов BASE и VIP, индивидуальные тренировки, карточка пробного.
7. Акции: афиши целиком, на обороте — условия.
8. Основательница и тренеры: 8 карточек-арок 4 × 2 с фото.
9. Массаж и косметология (три вкладки).
10. Первое занятие: пять шагов с рисунками.
11. Отзывы, вопросы (с рисунком «лента-вопрос»), контакты: буквы «Ждём вас в зале», схема проезда, онлайн-запись или заявка «Перезвоните мне».

Плюшки: заставка с логотипом при первом входе, золотые искры при клике, кольцо-курсор, объявление в углу (включается в кабинете), индикатор прокрутки-пилон.

## Кабинет `/admin`

- **Заявки** из формы «Перезвоните мне»: статусы «Новые / В работе / Готово», звонок, WhatsApp, Telegram, заметки. Новые проверяются каждые 30 секунд, их число видно в заголовке вкладки.
- **Статистика**: посещения, нажатия «Записаться» (переходы в YCLIENTS), звонки и заявки по дням за 7 / 30 / 90 дней. Без cookies и личных данных.
- **Содержимое сайта**: объявление, первый экран, цены, акции (с заменой афиш), направления, тренеры (с загрузкой фото), основательница, массаж и уход, первое занятие, отзывы, вопросы, контакты. «Сохранить на сайте» — изменения видны при следующем открытии страницы; «Вернуть исходный текст» — раздел снова берётся из `site.ts`.

Что где хранится: правки — ключ `pdk:content`, заявки — `pdk:requests`, счётчики — `pdk:stat:*`, фото — Vercel Blob (если задан `BLOB_READ_WRITE_TOKEN`), иначе Redis / `.data/media`. Все ключи начинаются с `pdk:`, поэтому общая база Redis с другими проектами не смешивается.

## Публикация на Vercel

1. Создать проект на Vercel из этой папки (`vercel` или через GitHub).
2. В Storage подключить Upstash Redis (переменные `KV_REST_API_URL`, `KV_REST_API_TOKEN` появятся сами), по желанию — Vercel Blob для фото.
3. В Environment Variables задать `ADMIN_PASSWORD` (и `ADMIN_SECRET`).
4. Без Redis сайт работает, но форма заявок и кабинет скажут, что хранилище не подключено.

## Где что менять в коде

| Что | Где |
| --- | --- |
| Тексты, цены, команда, отзывы, вопросы, ссылки по умолчанию | `src/config/site.ts` |
| Что можно править в кабинете | `src/admin/schema.ts` |
| API и хранилище | `server/router.ts`, `server/data.ts` |
| Фотографии | исходники в `_source/`, список в `scripts/photos.py`, готовые файлы в `public/photos/` |
| Цвета | `src/styles/tokens.css` |
| Рисунки и орнаменты | `src/components/ui/Art.tsx`, `src/styles/art.css` |
| Студия: вывеска, выключатель, экскурсия, схема зала | `src/components/sections/Studio.tsx`, `src/styles/studio.css` |
| Схема проезда, запись и форма заявки | `src/components/sections/Contacts.tsx` |
| Фото тренеров | `public/team/` (с YCLIENTS студии, 100×100) или загрузка в кабинете |
