# Pole Dance Kiseleva — сайт студии

Одностраничный сайт студии танцев на пилоне (Москва, ул. Саянская 7, м. Новогиреево) в серо-золотой гамме: графитово-серые и серебристые секции с золотом, собственные линейные рисунки и ар-деко орнаменты. Запись — через онлайн-запись студии на YCLIENTS; заявки «Перезвоните мне», статистика и правка текстов — в кабинете `/admin`.

Стек: Vite · React 19 · TypeScript · CSS; сервер — одна Vercel Function (`api/index.ts` → `server/router.ts`), данные в Upstash Redis (локально — папка `.data/`). Шрифты: Cormorant Garamond, Manrope, Jost.

## Запуск

```bash
npm install
npm run dev        # сайт http://127.0.0.1:5180, кабинет http://127.0.0.1:5180/admin
npm run build      # проверка типов и сборка в dist/ (сайт + кабинет)
npm run photos     # пересобрать фото из _source/ в public/photos/ и картинку-превью og.jpg
```

Пароль кабинета — в `.env.local` (`ADMIN_PASSWORD`), файл в git не попадает. Пример переменных — `.env.example`.

## Блоки страницы

1. Первый экран: золотая пыль, свет за курсором, меняющееся слово, фото в рамке с ар-деко аркой и лучами, рейтинг Яндекса.
2. Бегущая золотая строка с направлениями.
3. Студия: факты с рисунками, неоновая вывеска и выключатель «день / неон» (зал на фото переходит в вечерний неон, вывеска загорается), экскурсия по студии — нарисованная схема зала с точками, у каждой точки фото целиком и рассказ, автопрокрутка.
4. Направления: шесть направлений с рисунками, фото целиком на размытой подложке, тест «Какое направление вам подходит».
5. Галерея: 3D-карусель вокруг пилона и лента горизонтальных кадров.
6. Цены: калькулятор абонементов BASE и VIP, индивидуальные тренировки, карточка пробного.
7. Акции: афиши целиком, на обороте — условия.
8. Основательница и тренеры: 8 карточек-арок 4 × 2 с фото.
9. Массаж и косметология (три вкладки).
10. Первое занятие: пять шагов с рисунками.
11. Отзывы, вопросы (с рисунком «лента-вопрос»), контакты: буквы «Ждём вас в зале», схема проезда, онлайн-запись или заявка «Перезвоните мне».

Плюшки: заставка с логотипом при первом входе, золотые искры при клике, кольцо-курсор, объявление в углу (включается в кабинете), индикатор прокрутки-пилон.

## Кабинет `/admin`

Та же панель, что у ISPANA (github.com/MisterHarryX/ispana): тот же код экранов и стилей, перекрашенный в графитово-золотую гамму студии; мастера салона — тренеры студии, услуги — форматы занятий с ценами из раздела «Цены». Пароль — тот же, что у ISPANA (`ADMIN_PASSWORD`).

- **Заявки** — доска «Новая / В работе / Записана»: карточки перетаскиваются между колонками, поиск по имени, телефону и вопросу, фильтр по формату. Кнопка «+ Заявка» — добавить заявку, принятую по телефону или в переписке. Новые проверяются каждые 15 секунд: всплывает подсказка «Новая заявка → Открыть», число новых видно в заголовке вкладки; можно включить уведомления браузера (Настройки).
- **Карточка заявки** (боковая панель): статус, звонок / WhatsApp / Telegram, как удобнее связаться, день, время и длительность занятия (с предупреждением о пересечениях), тренер, формат и цена, «Оплачено», вопрос клиента, свои заметки (сохраняются сами), история статусов, «Занятие прошло», «Отменить», удаление.
- **Расписание**: неделя или день с колонками по тренерам; заявки без времени — слева, их ставят кликом на час или перетаскиванием; клик по пустому часу — поставить ждущую заявку или новую запись; рабочие часы студии подсвечены, линия «сейчас».
- **Архив**: завершённые и отменённые занятия по месяцам, сколько получено и сколько ждёт оплаты, средний чек, выгрузка в CSV для Excel.
- **Статистика**: посетители, нажатия «Записаться» (YCLIENTS), звонки, заявки, конверсия и время на сайте с сравнением с прошлым периодом; график по дням (сегодня — по часам); откуда пришли, как связывались, где нажимали «Записаться», до какого блока дочитали, устройства и браузеры, страны и города, лента «только что» и журнал входов в кабинет. Сверху — сколько человек на сайте прямо сейчас. Без cookies: посетитель — обезличенная метка, которая меняется каждый день; собственные визиты из кабинета не считаются.
- **Редактировать сайт** (`/?edit`, кнопка в кабинете или золотой ключик в подвале): сайт открывается с золотой панелью внизу. Нажмите на любой текст — он правится прямо на странице; на фото — заменить, скрыть или вернуть; «Вставить фото» — после любого абзаца; «Тексты» — список всех текстов с поиском; «Контакты» — телефон, ссылка на запись, соцсети. «Опубликовать» (или Ctrl + S) — и посетители видят изменения. Тексты из разделов кабинета сохраняются в те же разделы, что и формы, поэтому они всегда совпадают; цены меняются в разделе «Цены» (их считает калькулятор).
- **Разделы сайта**: формы для объявления, первого экрана, цен, акций, направлений, тренеров, основательницы, массажа и ухода, первого занятия, отзывов, вопросов, контактов. «Вернуть исходный текст» — раздел снова берётся из `site.ts`.
- **Настройки**: часы студии для расписания, редактор на сайте и сброс правок, сделанных прямо на странице, уведомления, состояние хранилища, выгрузка всех данных в JSON.

Старые заявки «Перезвоните мне» (до переноса панели) читаются автоматически: «Новые» → «Новая», «В работе» → «В работе», «Готово» → «Завершена», заметка — в «Мои заметки».

Что где хранится: правки — ключ `pdk:content` (правки на странице — в его поле `page`), заявки — `pdk:requests`, посещения — `pdk:events:<день>` (13 месяцев), входы в кабинет — `pdk:logins`, фото — Vercel Blob (если задан `BLOB_READ_WRITE_TOKEN`), иначе Redis / `.data/media`. Все ключи начинаются с `pdk:`, поэтому общая база Redis с другими проектами не смешивается.

## Где сайт в интернете

- **Сайт (временно):** https://misterharryx.github.io/pole-dance-kiseleva/ — статичная копия на GitHub Pages (ветка `gh-pages`). Своего сервера у неё нет: содержимое, заявки и счётчики она берёт с Vercel (`VITE_API_BASE` в `.env.pages`).
- **Кабинет и API:** https://pole-dance-kiseleva.vercel.app/admin — проект `pole-dance-kiseleva` на Vercel (команда `writelite`). Там же полная копия сайта.
- **Вход в кабинет:** золотой ключик в самом низу сайта; `/admin` на GitHub Pages тоже ведёт туда.
- **Код:** https://github.com/MisterHarryX/pole-dance-kiseleva (открытый; пароли и данные в репозиторий не попадают).
- **Пароль кабинета** — переменная `ADMIN_PASSWORD` в настройках проекта на Vercel (локально — `.env.local`).
- **База:** общая Upstash Redis команды (`icg-statistics`), данные этого сайта — только ключи `pdk:*`.

### Как обновить

```bash
vercel deploy --prod --scope writelite   # кабинет, API и копия сайта на Vercel
npm run deploy:pages                     # копия сайта на GitHub Pages
```

Тексты и цены, изменённые в кабинете, видны на обеих копиях сразу, без пересборки.

### Перенос на свой домен

Когда появится домен: подключить его к проекту на Vercel (там весь сайт с кабинетом) и добавить домен в `SITE_ORIGINS`, если копия на GitHub Pages останется.

## Что уточнить у студии

- Пробное без покупки абонемента: на карточке цен 700 ₽, на афише 500 ₽. На сайте в текстах 700 ₽ (меняется в кабинете → Цены), афиша показана целиком.

- Схема зала и схема проезда нарисованы условно, не в масштабе.
- Расписание групп и возраст в детских группах.
